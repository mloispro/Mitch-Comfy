# Protected Mitch LoRA milestone copies

These four locally trained keeper LoRAs are versioned with Git LFS so the proven workflow milestone is
recoverable from Git. They were trained from Mitch's private photographs; keep this repository private before
adding a remote or pushing the milestone.

`manifest.json` records the exact installed destination, byte count, SHA-256, and current role of each file.
The repository copies are backups; ComfyUI continues loading the installed copies under
`C:\projects\AI-Tools\ComfyUI\models\loras`.

The third-party Qwen and Krea2 LoRAs are not duplicated here. Their retained installation names are recorded in
`docs/STATUS.md`.
